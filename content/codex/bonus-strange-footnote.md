Easter egg. A footnote in the TVA manual reads: if you are reading this, you have been paying
attention. Please continue. Beneath it, in the same careful hand, is a second note that reads: the
Bureau does not forgive inattention, but it does reward its opposite. The footnote has never been
removed, although every edition has been reviewed. Somebody evidently wishes it to be found, and has
made sure that it will be found only by those who read to the end.
